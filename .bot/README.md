# ResearchKit · Bot 管理通信区

此目录仅供开发 AI 和独立管理 AI 交换任务、状态及证据；不是产品源码、运行依赖、测试依赖或原有项目文档。
原有事实文档：`README.md`、`CONTRIBUTING.md`、`RELEASE-NOTES.md`。

- project.json：固定仓库身份、任务路径、原有参考文档。
- tasks/*.md：轻量任务管理记录，状态只在重大变化时更新。
- 标题使用中文；关联提交可添加 `Task: RSK-BOT-001`（以实际任务 ID 为准）。
- 管理 AI 默认只读，原有开发/技术规则仍由各仓库既有文档维护。
- 不能让源码、Build/Test/发布脚本依赖此目录；删除后项目应可照常开发。
- 协议：https://github.com/YoYotouna/Bot/blob/main/protocol/SCHEMA.md
